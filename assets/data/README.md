# Archive data notes

These files are loaded by the static archive pages. Keep them valid JSON (double quotes, no trailing commas).

- `independence-events.json`: dated timeline records and the shared source catalogue.
- `wars.json`: conflict register, with year range, period label, kind, region, parties, summary, engagements, outcome, leaders and source IDs.
- `administrators.json`: central office-holders, including acting tenures, the Dominion period and the Secretary of State for India list.
- `revolutionaries.json`: short profiles with region, method, organisation/network, role, context and event year.
- `guess-bank.json`, `story-library.json`, `extended-quotes.json`: data formerly embedded in the original chronicle HTML.

For event and profile references, use source IDs from the event catalogue, and avoid adding unsourced exact dates or casualty figures. Use ranges or year-only dates when detail is uncertain. The lists are maintained as curated learning aids, not a complete record of every local event.
